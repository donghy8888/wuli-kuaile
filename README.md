# 快乐掌握物理 ⚛️

初中物理闯关小工具：19 章知识卡 + 闯关题、物理实验室模拟、公式抢答、单位连连看、错题本。纯 HTML/CSS/JS，无需构建，手机优先，进度存在浏览器 localStorage。

和「化学背背背」同一套设计：同样的首页卡片、HUD（得分/连击/时间）、3-2-1 倒计时、结算弹窗、错题本、Web Audio 合成音效（右上角可静音）。

## 玩法

| 模块 | 玩法 |
| --- | --- |
| 🗺️ 章节闯关 | 按人教版顺序 19 章（八上 6 章、八下 6 章、九年级 7 章）。每章先看 📌 知识要点 + 🧮 公式卡（含单位），再闯关：随机 8 题（单选 / 判断 / 计算填空，屏幕数字键盘），每题都有解析。正确率 ≥90% ★★★、≥70% ★★、≥50% ★。共 212 道题。 |
| 🔬 物理实验室 | 5 个可交互模拟，每个有 3–4 个小任务：🌈 光的反射与折射（入射角滑块、水/玻璃）、🔍 凸透镜成像（物距滑块，实时画光路，判断像的性质和应用）、⚖️ 杠杆平衡（挂钩码，F₁L₁ = F₂L₂）、🚢 浮力与浮沉（物块密度 × 酒精/水/盐水，画 G 和 F浮）、⚡ 欧姆定律电路（电源、定值电阻、滑动变阻器，电流表/电压表读数，电流流动动画）。 |
| ⚡ 公式抢答 | 限时：看名称选公式、看公式选名称、物理量的单位、常数与换算（光速、声速、1 kW·h、标准大气压……）。 |
| 🔗 单位连连看 | 物理量 ↔ 单位限时配对，清空一版 +5 秒。 |
| ⏱️ 限时大乱斗 | 所选范围（全部/八上/八下/九年级）的题目随机出。 |
| 📒 错题本 | 所有答错的题自动收录（含解析），“练错题”答对即移除。 |
| 📜 公式卡片 | 全部公式、常数换算、物理量与单位一页看完。 |

首页显示：⭐ 星星总数、🔥 连续学习天数、📝 答题数、🎯 正确率。

## 改题目

题目和知识卡都在 [`data.js`](data.js)，每章一个对象：

```js
C('题干', ['正确项', '干扰项1', '干扰项2', '干扰项3'], '解析'),   // 单选，显示时自动打乱
T('题干', false, '解析'),                                         // 判断
N('题干', 3600, 'm', '解析'),                                     // 计算填空
```

实验模拟在 [`sim.js`](sim.js)（SVG 代码绘制），每个实验的 `tasks` 是任务列表。

## 运行

```bash
python3 -m http.server 8000   # 打开 http://localhost:8000
python3 build.py              # 生成单文件离线版 dist/快乐掌握物理.html
```
